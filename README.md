# Wheel Rush 🏎️
A kid-friendly windshield-view racing game. Hold an iPad/iPhone sideways like a steering wheel and turn it to steer. Auto gas, Brake and Ultra Boost buttons, 4 long lap courses, Race and Time Trial modes (ghost car + Record Lights pacer). Built with three.js (MIT).
